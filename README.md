# Mechanica Descent

Mobile-first roguelike card game. Ivory rig, abandoned halls, Decon Bay.

Play: https://manlyburger.github.io/mechanica-descent/

```bash
npm install
npm run dev        # play locally
npm test           # engine tests
npm run sim        # balance sim (default 2,000 bot runs per row)
npm run build      # typecheck + production build
```

Design and build notes: [DESIGN.md](DESIGN.md).
